## Role Permissions

**Power Admin:** Full system access, all permissions
**System Admin:** User management, system settings, configuration
**Schedule Admin:** Schedule approval, conflict resolution, publishing
**Schedule Manager:** Schedule creation, data management, editing
**Teacher:** View own schedule, submit change requests, manage preferences
**Student:** View own schedule, view classmates (if enabled), submit feedback
